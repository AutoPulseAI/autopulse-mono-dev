  1. UI check (any computer with Chrome, on a local or test copy): node qa-sheet/ui-check.mjs --json /tmp/qa-ui.json — opens every page, tab and pop-up and checks no button is missing and no script or server error appears.

Issues

  1. Open: testers report it (a Fail/Blocked test, or a general problem on a screen). Every tester's report, note and screenshots stay with the bug.
  2. Fixed · awaiting lead tester: the developer says what changed and where (pull request). Not closed yet.
  3. Closed (verified): the lead tester re-tests and closes it. Only the lead tester can close a bug.
  4. Reopened: anyone can reopen it if it still fails; the cycle repeats. The bug's Full history keeps every step, tester and screenshot.
