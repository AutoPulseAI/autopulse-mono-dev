📅 Cascading Date Dropdowns

Smart date selection with automatic defaults and validation

✨ Key Features

  • Year → Month → Date cascading selection
  • Automatic defaults: May (5th month) and 2nd day
  • Smart validation: Correct number of days per month
  • Responsive design: Works on all devices
  • Easy integration: Simple Blade component

🔧 How to Use

Include this component in your Blade templates:

<x-date-dropdowns name="birth_date" id="birth-date-dropdowns" :defaultYear="1990" :defaultMonth="5" :defaultDate="2" required />

Available Props:

  • name - Base name for the form fields
  • id - Unique ID for the container
  • class - Additional CSS classes
  • required - Make fields required
  • defaultYear - Default year (defaults to current year)
  • defaultMonth - Default month (defaults to 5 = May)
  • defaultDate - Default date (defaults to 2)
  • minYear - Minimum year (defaults to 1900)
  • maxYear - Maximum year (defaults to current year + 10)

📱 JavaScript API

Control the dropdowns programmatically:

// Get selected date const date = getSelectedDate('birth_date'); // Set specific date setDate('birth_date', 2025, 3, 15);

🎨 Styling

The component includes responsive Bootstrap styling and can be customized with CSS:
