DealerTrack export file-type reference

Common file format
- Encoding: tab-separated text (TSV); the separator between columns is a literal tab (\\t).
- One header row is followed by data rows. Text fields are not quoted in these exports.
- Empty values are represented by adjacent tabs.
- Dates use M/D/YYYY; numeric money/quantity fields may contain commas.
- File name pattern: DVD46315_YYYYMMDD_HHMM_<TYPE>.txt. Dealer identifiers are DV Dealer ID and Vendor Dealer ID; both are DVD46315.
- SV repeating values: pipe (|) separates operation/line groups; caret (^) separates multiple values within a group. Preserve empty positions when splitting.
