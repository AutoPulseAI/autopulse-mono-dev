Purpose
-------
Active bulk-upload response workflow. It receives one uploaded Lead at /bulk-upload, loads dealer and inventory context, chooses email or SMS follow-up from the Lead preference, classifies intent/visit/booking/managerial-review behavior, and returns a formatted outreach response.

High-level flow
---------------
  POST /bulk-upload
    -> extract uploaded Lead fields and dealer ID
    -> load dealer/store details
    -> query inventory by VIN when supplied, otherwise by make/model/year
    -> classify inquiry, intent, sentiment, visit/booking, and managerial-review state
    -> branch on followup_preference:
         sms   -> short phone/SMS response
         email -> full email response
    -> use inventory, store hours, intent bank, and CTA bank
    -> format response and return

----------------------

Inactive walkthrough/older email communication workflow. It demonstrates the core email, ADF/XML, phone, inventory, appointment, DND, and response branches that workflow-3 later expanded with campaign and attachment processing.

High-level flow
---------------
  POST /incoming-email-messages
    -> extract and clean email plus old conversation
    -> detect ADF/XML versus ordinary email
         ADF -> decode/sanitize/parse XML -> inventory lookup -> ADF email/phone response
         ordinary email -> customer/vehicle extraction -> context/inventory lookup
    -> classify DND, communication mode, inquiry, intent, visit, booking, and review needs
    -> generate dealer-aware response and wrap email output as HTML
    -> return selected response formatter
